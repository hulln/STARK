# nh-work

This folder contains local material used with this STARK fork: custom configs, helper and analysis scripts, notes, small checked-in example outputs, and moved local sample data.

The upstream STARK source code and default top-level files are kept mostly unchanged so future merges from `clarinsi/STARK` remain straightforward.

Large generated outputs should not be committed. Put rerunnable large outputs in ignored local locations such as `nh-work/outputs/`, or outside the repository.
